# Web profesional de Guillermo Guerrero-Vacas — versión 2

Sitio estático con **Jekyll**, preparado para **GitHub Pages**. El diseño mantiene la orientación académica, científica y de transferencia de la primera maqueta.

## Publicación gratuita

1. Crear una cuenta de GitHub y un repositorio **público** llamado `USUARIO.github.io`.
2. Descomprimir este ZIP y subir **el contenido de la carpeta**, no la carpeta contenedora. Deben quedar `_config.yml` e `index.html` en la raíz del repositorio.
3. En GitHub, ir a **Settings → Pages**; seleccionar **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Esperar a que se publique en `https://USUARIO.github.io/`. Para un repositorio con otro nombre, ajustar `baseurl` en `_config.yml`.
5. **No publicar todavía sin revisar** textos, enlaces, datos personales y páginas marcadas como borrador.

GitHub Pages ejecuta Jekyll para construir las páginas. No requiere contratar hosting ni instalar Jekyll para publicar. Para probar localmente con Jekyll se necesitan Ruby y las dependencias correspondientes; abrir `index.html` directamente no mostrará el contenido generado por Liquid.
