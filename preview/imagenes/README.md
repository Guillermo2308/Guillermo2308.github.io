# Banco de imágenes de la web académica

Esta carpeta contiene las fotografías propias y figuras científicas autorizadas para su publicación en la web de Guillermo Guerrero Vacas.

Organización prevista:
- `superficies/`: recubrimientos, moldes, ensayos de mojabilidad, desgaste y eliminación.
- `fabricacion-aditiva/`: fabricación aditiva metálica y polimérica, utillajes y piezas.
- `conformado/`: SPIF, trefilado, mecanizado y modelos de proceso.
- `materiales-sostenibles/`: lana, compuestos, probetas y ensayos.
- `docencia/`: equipos docentes, CAD/CAM/CAE y prácticas.
- `perfil/`: fotografías personales autorizadas.

Para cada imagen se recomienda anotar autoría, procedencia, artículo o proyecto asociado y permiso/licencia de publicación. Utilizar nombres descriptivos sin espacios ni caracteres especiales; optimizar JPEG/WEBP para fotografías y PNG/SVG para esquemas.

Las carpetas temáticas se crearán cuando se incorpore su primera imagen.
